OXRANALOUTABACLIENT — Internal Cheat для CS2
Современный internal чит для Counter-Strike 2 с акцентом на стабильность, качество и удобство.
Основные возможности:

Visuals (ESP, Glow, Chams, Snaplines, Radar Hack и т.д.)
Aimbot + Triggerbot + Backtrack
Misc (BunnyHop, AutoStrafe, Skin Changer, Knife Changer, Hit Sound и др.)
ImGui меню с красивым дизайном и шрифтами
Кастомные звуки и визуальные эффекты

Проект написан на C++ с использованием MinHook + ImGui. Работает через инжект в процесс игры.
Важная информация для пользователей и разработчиков:
Обновления оффсетов
При выходе новых обновлений игры скидывайте актуальные offsets в папку:
OXRANALOUATABACILITY/output
Там уже лежит структура для удобного обновления. Это сильно ускоряет поддержку чита после патчей Valve.
Как установить / использовать:

Скомпилировать проект в Release (x64)
Запустить CS2
Инжектить DLL через инжектор на ваш выбор
Открыть меню клавишей INSERT
